# Sprint S2-2 Review — عرض الكتالوج العام (Public Catalog)

## التاريخ: 2026-03-10

## الهدف
بناء صفحات عرض الكتالوج العامة للخدمات والمنتجات والمصورين مع فلاتر التصنيف والترتيب حسب السعر والبحث المتقدم.

## المُنجزات

### الصفحات المُحدّثة
- `/services` — كتالوج الخدمات مع فلتر تصنيفات + ترتيب سعر + بطاقات عرض
- `/products` — كتالوج المنتجات مع فلتر تصنيفات + ترتيب سعر + شارات المخزون
- `/photographers` — ملفات المصورين مع التقييمات والتخصصات والخبرة

### الصفحات الجديدة
- `/search` — صفحة بحث متقدم باستخدام `search_catalog` RPC
- `src/app/search/_components/search-form.tsx` — نموذج بحث مع فلتر النوع

## القرارات التقنية
- `searchParams` كـ Promise (Next.js 16 async API)
- `revalidate = 3600` لـ ISR على صفحات الكتالوج
- فلاتر التصنيف عبر URL params
- ترتيب السعر تصاعدي/تنازلي عبر query params
- تكامل `search_catalog` RPC للبحث النصي الكامل
