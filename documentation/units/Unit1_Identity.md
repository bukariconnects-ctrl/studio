# الوحدة الأولى: وحدة الأساس والهوية (Core Foundation & Identity Module)

---

## الوصف

تُعد هذه الوحدة "النظام العصبي" للمشروع، حيث تضع القواعد الأساسية للأمان، الهوية، والواجهة. الغاية منها هي بناء بوابة الدخول الموحدة لكافة أنواع المستخدمين، والتأكد من أن كل شخص يصل فقط إلى ما هو مصرح له به (RBAC). كما تشمل تهيئة الهيكل الإنشائي للموقع (Layouts) والاتصال الأولي بقاعدة البيانات والصفحات الثابتة (السياسات).

**لا يمكن لأي وحدة أخرى أن تعمل بدون هذه الوحدة.** فهي تؤسس اتصال Next.js مع Supabase، وتبني نظام تسجيل الدخول/الإنشاء، وتحدد أدوار المستخدمين (زائر، عميل، مصور، مدير)، وتؤمن المسارات عبر Middleware.

---

## المتطلبات المرتبطة

### المتطلبات الوظيفية (Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **FR-V5** | إنشاء حساب جديد للزائر | استخدام `signUp` من Supabase Auth مع التحقق عبر React Hook Form و Zod |
| **FR-V6** | عرض السياسات والشروط | صفحات ثابتة (Static Pages) مع جلب المحتوى من جدول `system_settings` |
| **FR-C1** | المصادقة وتسجيل الدخول | استخدام `signInWithPassword` مع تخزين الجلسة في Cookies مشفرة |
| **FR-C2** | إدارة الملف الشخصي | تحديث البيانات عبر Server Actions مع التحقق عبر Zod |
| **FR-C10** | استرجاع كلمة المرور | تفعيل Email Templates في Supabase لإرسال رابط إعادة التعيين |
| **FR-P1** | دخول المصور بناءً على الدور | قراءة Metadata من حساب Supabase والتوجيه للوحة التحكم `/photographer` |
| **FR-A1** | دخول المدير بناءً على الدور | قراءة Metadata من حساب Supabase والتوجيه للوحة التحكم `/admin` |

### المتطلبات غير الوظيفية (Non-Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **NFR-SEC1** | تشفير البيانات الحساسة | خوارزمية bcrypt في Supabase Auth + تفعيل سياسات RLS |
| **NFR-SEC2** | إدارة الجلسات وحماية المسارات | Next.js Middleware لفحص الجلسة والدور قبل تحميل أي صفحة محمية |
| **NFR-SEC3** | الامتثال لمعايير الخصوصية (GDPR) | خانة موافقة في نماذج التسجيل مع تخزين طابع زمني في `profiles.gdpr_consent_at` |
| **NFR-US1** | التصميم المتجاوب للهيكل | Tailwind CSS لبناء Root Layout و Navigation Bar متجاوب |

## الجداول المتأثرة

| الجدول | نوع التأثير | الوصف |
| :--- | :--- | :--- |
| `profiles` | إنشاء / قراءة / تعديل | الملفات الشخصية للمستخدمين (FR-C2) - يُنشأ تلقائياً عبر Trigger عند التسجيل |
| `roles` | قراءة | تحديد الأدوار المتاحة في النظام |
| `permissions` | قراءة | تحديد الصلاحيات المتاحة |
| `role_permissions` | قراءة | ربط الصلاحيات بالأدوار |
| `user_roles` | إنشاء / قراءة | تعيين الدور للمستخدم الجديد (client افتراضياً) والتحقق من الدور عند الدخول |
| `system_settings` | قراءة | جلب محتوى صفحات السياسات والشروط (FR-V6) |
| `auth.users` | إنشاء / قراءة | جدول Supabase Auth الأساسي للمصادقة |

## المستخدمون المتفاعلون

| المستخدم | المهام داخل هذه الوحدة |
| :--- | :--- |
| **الزائر (Visitor)** | إنشاء حساب جديد (FR-V5)، عرض السياسات والشروط (FR-V6) |
| **العميل (Client)** | تسجيل الدخول (FR-C1)، إدارة الملف الشخصي (FR-C2)، استرجاع كلمة المرور (FR-C10) |
| **المصور (Photographer)** | تسجيل الدخول بصلاحية مصور (FR-P1) |
| **المدير (Administrator)** | تسجيل الدخول بصلاحية مدير (FR-A1) |
