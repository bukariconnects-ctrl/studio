# الوحدة الثانية: وحدة الكتالوج والعرض (Catalog & Display Module)

---

## الوصف

هذه الوحدة هي "واجهة المتجر" (Storefront) والخدمات. الغاية منها هي عرض القيمة التي يقدمها الإستوديو بشكل جذاب وسريع ومتوافق مع محركات البحث (SEO). تركز الوحدة على جلب البيانات الضخمة (صور الخدمات، تفاصيل الباقات، منتجات المتجر) وعرضها بكفاءة، مع بناء نظام "سلة المشتريات" المبدئي.

**تعتمد على الوحدة الأولى** (وجود مستخدمين مسجلين لإدارة السلة). قبل أن يتمكن العميل من الحجز أو الدفع، يجب أن يكون هناك "محتوى" معروض. فصل نظام التجارة الإلكترونية (المنتجات المادية) عن نظام الحجوزات (الخدمات الزمنية) يقلل التعقيد ويجعل النظام قابلاً للتوسع.

## المتطلبات المرتبطة

### المتطلبات الوظيفية (Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **FR-V1** | تصفح الخدمات والباقات | Next.js Server Components لجلب البيانات من جدول `services` مع رندر على السيرفر لـ SEO |
| **FR-V2** | تصفح المتجر والمعدات | جلب المنتجات مع صورها واستخدام Next.js Image Optimization لضغط الصور وتحويلها لـ WebP |
| **FR-V3** | البحث المتقدم | Supabase Postgres Search عبر دالة `search_catalog` RPC للبحث في الأسماء والأوصاف والتصنيفات |
| **FR-V4** | استعراض فريق المصورين | عرض ملفات المصورين (Profiles) مع نماذج الأعمال والتقييمات وتقنية Blur Placeholder |
| **FR-C5** | إدارة سلة المشتريات | Zustand لإدارة حالة السلة مع حفظ في localStorage + نسخة احتياطية في جدول `cart_items` |

### المتطلبات غير الوظيفية (Non-Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **NFR-PE2** | سرعة استرجاع البيانات (فهرسة) | Database Indexes على أعمدة (اسم المنتج، تصنيف الخدمة، السعر) |
| **NFR-PE3** | التخزين المؤقت (Caching) | تفعيل `revalidate` في Next.js لصفحات الخدمات (تحديث كل ساعة) |
| **NFR-US2** | مكونات العرض التفاعلية | Shadcn/UI لبناء القوائم المنسدلة، البطاقات (Cards)، النوافذ المنبثقة (Modals) |

## الجداول المتأثرة

| الجدول | نوع التأثير | الوصف |
| :--- | :--- | :--- |
| `services` | قراءة | عرض الخدمات في الكتالوج (FR-V1) |
| `service_categories` | قراءة | تصنيف وفلترة الخدمات |
| `packages` | قراءة | عرض الباقات المتاحة (FR-V1) |
| `package_services` | قراءة | تفاصيل محتوى كل باقة |
| `products` | قراءة | عرض المنتجات في المتجر (FR-V2) |
| `product_categories` | قراءة | تصنيف وفلترة المنتجات |
| `product_images` | قراءة | صور المنتجات المتعددة |
| `photographers` | قراءة | بيانات فريق المصورين (FR-V4) |
| `profiles` | قراءة | أسماء وصور المصورين |
| `reviews` | قراءة | تقييمات المصورين والخدمات (لعرضها في صفحات الكتالوج) |
| `cart_items` | إنشاء / قراءة / تعديل / حذف | إدارة سلة المشتريات (FR-C5) - نسخة احتياطية |

## المستخدمون المتفاعلون

| المستخدم | المهام داخل هذه الوحدة |
| :--- | :--- |
| **الزائر (Visitor)** | تصفح الخدمات والباقات (FR-V1)، تصفح المتجر (FR-V2)، البحث المتقدم (FR-V3)، استعراض المصورين (FR-V4) |
| **العميل (Client)** | جميع مهام الزائر + إدارة سلة المشتريات (FR-C5) |
