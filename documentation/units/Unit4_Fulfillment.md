# الوحدة الرابعة: وحدة العمليات والتنفيذ (Operations & Fulfillment Module)

---

## الوصف

هذه الوحدة هي "ميدان العمل" الخاص بالمصورين. الغاية منها هي إدارة مرحلة ما بعد الحجز، أي تنفيذ جلسة التصوير وتسليم الصور. تركز الوحدة على إدارة الملفات الضخمة (صور عالية الجودة) وتدفق العمل بين المصور والعميل، مع توفير نظام تنبيهات لحظي لضمان سرعة التنفيذ والالتزام بالمواعيد.

**تعتمد على الوحدة الثالثة** (لا يمكن للمصور أداء عمله إلا بعد أن يقوم العميل بالحجز). عزل هذه الوحدة يضمن أن واجهة المصورين خفيفة ومخصصة فقط لأداء مهامهم دون التداخل مع تعقيدات الإدارة أو المتجر.

## المتطلبات المرتبطة

### المتطلبات الوظيفية (Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **FR-P2** | استعراض جدول المهام المنظم | لوحة تحكم مخصصة في `/photographer` مع جلب الجلسات المسندة للمصور فقط عبر RLS |
| **FR-P3** | عرض تفاصيل الجلسة للتحضير | Server Components لجلب بيانات العميل وملاحظاته (رقم الهاتف، نوع الباقة، الموقع) |
| **FR-P4** | تحديث حالة الجلسة | زر "إتمام الجلسة" يستدعي Server Action لتحديث الحالة إلى "completed" مع تسجيل Timestamp |
| **FR-P5** | رفع مخرجات العمل (الصور) | Supabase Storage مع Resumable Uploads. حفظ الصور في Buckets خاصة وتخزين الروابط في `album_photos` |
| **FR-P6** | تلقي الإشعارات الفورية | Supabase Realtime (Broadcast) لإرسال تنبيه فوري (Toast Notification) عند إسناد مهمة جديدة |
| **FR-C9** | نظام التقييم والمراجعات | واجهة تقييم تظهر للعميل بعد تغيير الحالة إلى "completed". يُخزن في جدول `reviews` مع تحديث آلي لمتوسط تقييم المصور عبر Trigger |

### متطلبات النظام (System Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **SR3** | بوابة المصور وجدول المهام | Next.js App Router مع مسار `/photographer` محمي بـ Middleware و RLS |

### المتطلبات غير الوظيفية (Non-Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **NFR-SEC2** | إدارة الجلسات الآمنة للمصور | Next.js Middleware للتأكد من دور "photographer" وأنه المسند إليه الحجز تحديداً |

## الجداول المتأثرة

| الجدول | نوع التأثير | الوصف |
| :--- | :--- | :--- |
| `bookings` | قراءة / تعديل | **الجدول الأساسي:** جلب الجلسات المسندة (FR-P2, FR-P3)، تحديث الحالة (FR-P4) |
| `albums` | إنشاء / قراءة / تعديل | إنشاء ألبومات لكل جلسة وتنظيم الصور (FR-P5) |
| `album_photos` | إنشاء / قراءة | رفع الصور وتخزين روابطها (FR-P5) |
| `reviews` | إنشاء / قراءة | تقييم العميل للمصور والخدمة (FR-C9) |
| `photographers` | قراءة / تعديل | تحديث متوسط التقييم آلياً عبر Trigger `update_photographer_rating` |
| `profiles` | قراءة | جلب بيانات العميل لعرضها للمصور (FR-P3) |
| `services` | قراءة | تفاصيل الخدمة المحجوزة |
| `packages` | قراءة | تفاصيل الباقة المحجوزة |
| `notifications` | إنشاء / قراءة / تعديل | إشعارات المصور اللحظية (FR-P6) - تُنشأ عبر Trigger `notify_booking_status_change` |
| `photographer_unavailability` | إنشاء / قراءة / تعديل / حذف | إدارة فترات عدم التوفر |

## المستخدمون المتفاعلون

| المستخدم | المهام داخل هذه الوحدة |
| :--- | :--- |
| **المصور (Photographer)** | استعراض جدول المهام (FR-P2)، عرض تفاصيل الجلسة (FR-P3)، تحديث حالة الجلسة (FR-P4)، رفع الصور (FR-P5)، تلقي الإشعارات (FR-P6) |
| **العميل (Client)** | تقييم المصور والخدمة بعد إتمام الجلسة (FR-C9)، استعراض ألبوم الصور النهائي |
