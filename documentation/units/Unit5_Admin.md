# الوحدة الخامسة: وحدة الإدارة والتحليل (Admin Management & Analytics Module)

---

## الوصف

تُعتبر هذه الوحدة هي "برج المراقبة" للنظام بالكامل. الغاية منها هي تمكين الإدارة من السيطرة الكاملة على الموارد البشرية (المصورين) والمادية (المتجر والمخزون) والمالية. تركز الوحدة على تجميع البيانات المبعثرة في النظام وتحويلها إلى تقارير بصرية (Charts) وقرارات إدارية، مع توفير أدوات لإدارة المحتوى والرد على استفسارات العملاء.

**تأتي بعد اكتمال دورة البيانات** (مستخدمون، مبيعات، حجوزات، صور) من الوحدات السابقة (1-4) لكي يتمكن المدير من استعراضها، إدارتها، واستخراج التقارير منها. لو تم بناء لوحة التحكم أولاً لكانت فارغة ولا يمكن اختبارها.

## المتطلبات المرتبطة

### المتطلبات الوظيفية (Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **FR-A1** | لوحة التحكم والوصول الشامل | واجهة Admin Dashboard محمية بـ Next.js Middleware مع التحقق من دور "admin" في Supabase Metadata |
| **FR-A3** | إدارة الخدمات والباقات والأسعار | واجهة CRUD متقدمة لإدارة جداول `services`، `packages`، `service_categories` |
| **FR-A4** | إدارة المتجر والمخزون اللحظي | واجهة CRUD لإدارة `products` مع تحديث المخزون لحظياً عبر Server Actions. مراقبة المخزون عبر `v_low_stock_products` |
| **FR-A5** | إدارة فريق العمل والمستخدمين | Supabase Auth Admin API (Service Role) لإنشاء حسابات المصورين، حظر مستخدمين، تعديل بيانات |
| **FR-A6** | استخراج التقارير والـ KPIs | SQL Views (`v_daily_revenue`, `v_photographer_performance`) + دالة `get_admin_dashboard_stats` مع عرض بصري عبر Recharts |
| **FR-A7** | إدارة الشكاوى والتواصل الداعم | نظام تذاكر دعم: قراءة الشكاوى من جدول `tickets`، الرد عبر `ticket_replies`، إرسال إشعارات بريدية |
| **FR-A9** | إدارة المحتوى الديناميكي (CMS) | واجهة لتعديل نصوص "من نحن"، "السياسات"، بيانات التواصل في جدول `system_settings` |
| **FR-A10** | تصدير البيانات (Export) | jsPDF (لـ PDF) و xlsx (لـ Excel) عبر Next.js API Routes. معالجة البيانات في السيرفر |
| **FR-A11** | إدارة الأدوار والصلاحيات (RBAC) | إدارة جداول `roles`، `permissions`، `role_permissions`، `user_roles` لتحديد صلاحيات الموظفين |

### متطلبات النظام (System Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **SR6** | لوحة تحكم إدارية وتحليلية شاملة | Next.js App Router مع مسار `/admin` محمي + واجهات التقارير والإدارة |

### المتطلبات غير الوظيفية (Non-Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **NFR-AR4** | مراقبة النظام (Logging) | Supabase Logs + جدول `system_logs` لتسجيل الأخطاء والعمليات الحساسة |

## الجداول المتأثرة

| الجدول | نوع التأثير | الوصف |
| :--- | :--- | :--- |
| `services` | إنشاء / قراءة / تعديل / حذف | إدارة الخدمات (FR-A3) |
| `service_categories` | إنشاء / قراءة / تعديل / حذف | إدارة تصنيفات الخدمات (FR-A3) |
| `packages` | إنشاء / قراءة / تعديل / حذف | إدارة الباقات (FR-A3) |
| `package_services` | إنشاء / قراءة / تعديل / حذف | ربط الخدمات بالباقات (FR-A3) |
| `products` | إنشاء / قراءة / تعديل / حذف | إدارة المنتجات والمخزون (FR-A4) |
| `product_categories` | إنشاء / قراءة / تعديل / حذف | إدارة تصنيفات المنتجات (FR-A4) |
| `product_images` | إنشاء / قراءة / تعديل / حذف | إدارة صور المنتجات (FR-A4) |
| `profiles` | قراءة / تعديل | إدارة حسابات المستخدمين (FR-A5) |
| `photographers` | إنشاء / قراءة / تعديل / حذف | إدارة فريق المصورين (FR-A5) |
| `roles` | إنشاء / قراءة / تعديل / حذف | إدارة الأدوار (FR-A11) |
| `permissions` | إنشاء / قراءة / تعديل / حذف | إدارة الصلاحيات (FR-A11) |
| `role_permissions` | إنشاء / قراءة / تعديل / حذف | ربط الصلاحيات بالأدوار (FR-A11) |
| `user_roles` | إنشاء / قراءة / تعديل / حذف | تعيين أدوار المستخدمين (FR-A5, FR-A11) |
| `bookings` | قراءة / تعديل | مراقبة الحجوزات واستخراج التقارير (FR-A6) |
| `orders` | قراءة / تعديل | مراقبة الطلبات واستخراج التقارير (FR-A6) |
| `invoices` | قراءة | استخراج التقارير المالية (FR-A6, FR-A10) |
| `tickets` | قراءة / تعديل | إدارة الشكاوى (FR-A7) |
| `ticket_replies` | إنشاء / قراءة | الرد على الشكاوى (FR-A7) |
| `system_settings` | قراءة / تعديل | إدارة المحتوى والإعدادات (FR-A9) |
| `system_logs` | قراءة | مراقبة النظام والأخطاء (NFR-AR4) |
| `reviews` | قراءة / تعديل | الإشراف على التقييمات (إخفاء/حذف غير اللائقة) |
| `user_activity_logs` | قراءة | تحليل سلوك المستخدمين |
