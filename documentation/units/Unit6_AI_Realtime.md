# الوحدة السادسة: وحدة الذكاء الاصطناعي والتفاعل اللحظي (AI & Realtime Enhancements Module)

---

## الوصف

هذه هي "وحدة القيمة المضافة" التي تميز النظام عن المنافسين. الغاية منها هي أتمتة العمليات الذهنية (مثل التوصيات والجدولة) وتوفير تجربة مستخدم تفاعلية لحظية. تركز الوحدة على دمج نماذج الذكاء الاصطناعي مع بيانات النظام الحقيقية، وتفعيل قنوات الاتصال الفوري بين كافة أطراف المنصة لضمان سرعة الاستجابة.

**تُترك دائماً للمرحلة الأخيرة** في هندسة البرمجيات لأن الذكاء الاصطناعي يحتاج إلى بيانات تاريخية (سجل المشتريات والحجوزات) ليعمل بشكل صحيح ويقدم توصيات دقيقة. كذلك الإشعارات اللحظية والتقييمات تعتبر ميزات "تحسينية" تُضاف بعد استقرار الوظائف الأساسية.

---

## المتطلبات المرتبطة

### المتطلبات الوظيفية (Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **FR-C7** | التوصيات الذكية ومساعد المظهر | Supabase Edge Functions تتواصل مع OpenAI API. تستخدم pgvector لتخزين تفضيلات العميل كـ Embeddings والبحث عن المنتجات الأكثر تشابهاً عبر دالة `get_ai_recommendations` |
| **FR-C9** | نظام التقييم التفاعلي | واجهة تقييم ذكية تظهر فور انتهاء الجلسة. Database Trigger `update_photographer_rating` يحدث متوسط تقييم المصور آلياً |
| **FR-P6** | الإشعارات اللحظية للمصورين | Supabase Realtime (Channels) - قناة لكل مستخدم. عند تغيير حالة حجز أو وصول رسالة تصل إشارة للمتصفح فوراً وتظهر كـ Toast Notification (Sonner) |
| **FR-A8** | الجدولة الذكية للإدارة | خوارزمية في Edge Function تحلل أوقات الذروة وتوزع الحجوزات على المصورين المتاحين (Load Balancing) عبر دالة `smart_assign_photographer` |

### متطلبات النظام (System Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **SR4** | دمج تقنيات الذكاء الاصطناعي | Edge Functions + OpenAI API + pgvector للتوصيات ومساعد المظهر |
| **SR7** | قنوات تواصل وتقييم متكاملة | Supabase Realtime للإشعارات الفورية + نظام المراجعات والتقييمات |

### المتطلبات غير الوظيفية (Non-Functional Requirements)

| رمز المتطلب | الوصف | آلية التطبيق |
| :--- | :--- | :--- |
| **NFR-PE1** | المعالجة المتزامنة والذكية | Next.js Server Actions مع Optimistic UI - تظهر النتيجة فوراً بينما يتم التحديث في الخلفية |
| **NFR-SEC3** | الامتثال للخصوصية (GDPR) | خانة موافقة في نماذج التسجيل مع تخزين طابع زمني للموافقة في `profiles.gdpr_consent_at` |

## الجداول المتأثرة

| الجدول | نوع التأثير | الوصف |
| :--- | :--- | :--- |
| `user_embeddings` | إنشاء / قراءة / تعديل | متجهات تفضيلات المستخدم لمحرك التوصيات (FR-C7) - pgvector |
| `item_embeddings` | إنشاء / قراءة / تعديل | متجهات المنتجات والخدمات للبحث بالتشابه (FR-C7) - pgvector |
| `user_activity_logs` | إنشاء / قراءة | تتبع سلوك المستخدم لتغذية محرك التوصيات |
| `reviews` | إنشاء / قراءة | نظام التقييم التفاعلي (FR-C9) |
| `photographers` | تعديل | تحديث متوسط التقييم آلياً عبر Trigger (FR-C9) |
| `notifications` | إنشاء / قراءة / تعديل | **الجدول الأساسي للإشعارات اللحظية:** يعمل مع Supabase Realtime (FR-P6). يتم إنشاء الإشعارات عبر Triggers وتُبث لحظياً عبر WebSocket |
| `bookings` | قراءة | تحليل بيانات الحجوزات للجدولة الذكية (FR-A8) |
| `profiles` | قراءة | بيانات المستخدم لتخصيص التوصيات |

---

## المستخدمون المتفاعلون

| المستخدم | المهام داخل هذه الوحدة |
| :--- | :--- |
| **العميل (Client)** | استلام التوصيات الذكية (FR-C7)، استخدام مساعد المظهر AI، تقييم المصورين والخدمات (FR-C9)، استقبال الإشعارات اللحظية لحالة الحجوزات |
| **المصور (Photographer)** | تلقي الإشعارات الفورية عند إسناد مهام جديدة (FR-P6)، الاستفادة من الجدولة الذكية |
| **المدير (Administrator)** | استخدام الجدولة الذكية لتوزيع المهام (FR-A8)، استقبال إشعارات لحظية لمراقبة النظام |
