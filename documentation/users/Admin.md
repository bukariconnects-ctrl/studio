# المدير (Administrator)

---

## الوصف

هو المتحكم الشامل في النظام. يمتلك صلاحيات إدارية ومالية وتقنية واسعة لضمان سير العمل واستمراريته. يُشرف على جميع جوانب المنصة من خلال لوحة تحكم شاملة (`/admin`) تتيح له إدارة المستخدمين، الخدمات، المخزون، الحجوزات، التقارير المالية، والشكاوى. يستخدم أدوات الذكاء الاصطناعي لتحسين توزيع المهام واتخاذ القرارات الاستراتيجية.

---

## المهام التفصيلية

| رمز المتطلب | المهمة | الوصف التفصيلي |
| :--- | :--- | :--- |
| **FR-A1** | الوصول الشامل والمصادقة الإدارية | تسجيل الدخول مع التحقق من دور "admin" في Supabase Metadata. لوحة التحكم محمية بـ Next.js Middleware يمنع أي مستخدم غير مخول من الوصول للمسار `/admin/*`. |
| **FR-A2** | إدارة طلبات الحجز والجدولة | قبول أو رفض طلبات الحجز الواردة وتعيين المصورين للجلسات. يتم استخدام Database Triggers لتحديث المواعيد والإشعارات آلياً عند تغيير الحالة. |
| **FR-A3** | إدارة الخدمات والباقات والأسعار | إضافة وتعديل وحذف الخدمات والباقات وتصنيفاتها وأسعارها في قاعدة البيانات عبر واجهة CRUD متقدمة. |
| **FR-A4** | إدارة المتجر والمخزون اللحظي | إدارة المنتجات (إضافة/تعديل/حذف)، تحديث كميات المخزون لحظياً عبر Server Actions. مراقبة المنتجات منخفضة المخزون عبر عرض `v_low_stock_products`. |
| **FR-A5** | إدارة فريق العمل والمستخدمين | إنشاء حسابات المصورين، حظر مستخدمين، تعديل البيانات الشخصية عبر Supabase Auth Admin API (Service Role). |
| **FR-A6** | استخراج التقارير والإحصائيات (KPIs) | مراقبة مؤشرات الأداء: إجمالي الإيرادات، عدد الحجوزات، معدل التقييمات، المنتجات منخفضة المخزون. يتم عرضها بصرياً عبر Recharts باستخدام SQL Views ودالة `get_admin_dashboard_stats`. |
| **FR-A7** | إدارة الشكاوى والتواصل الداعم | إدارة نظام تذاكر الدعم (Support Tickets): قراءة الشكاوى، تعيين الأولويات، الرد على العملاء، تغيير حالة التذكرة. يتم إرسال إشعارات بريدية للعميل عند الرد. |
| **FR-A8** | دعم الذكاء الاصطناعي للإدارة | استخدام خوارزمية الجدولة الذكية (`smart_assign_photographer`) لتوزيع الحجوزات على المصورين المتاحين بناءً على أوقات الذروة وعبء العمل (Load Balancing) عبر Edge Functions. |
| **FR-A9** | إدارة المحتوى الديناميكي (CMS) | تعديل نصوص صفحات "من نحن"، "السياسات"، "شروط الخدمة"، بيانات التواصل، ساعات العمل. تُخزن في جدول `system_settings` وتُجلب في Next.js ديناميكياً. |
| **FR-A10** | تصدير البيانات (Export Data) | تصدير التقارير المالية والإحصائية بصيغ PDF (عبر jsPDF) و Excel (عبر xlsx). تتم المعالجة في السيرفر عبر Next.js API Routes لتقليل الضغط على المتصفح. |
| **FR-A11** | إدارة الأدوار والصلاحيات (RBAC) | تحديد صلاحيات الموظفين (المصورين) وتعيين أدوار جديدة. إدارة جداول `roles`، `permissions`، `role_permissions`، `user_roles`. |

## الوحدات البرمجية المرتبطة

| الوحدة | الاسم | نوع التفاعل |
| :--- | :--- | :--- |
| **الوحدة 1** | وحدة الأساس والهوية (Core Foundation & Identity) | تسجيل الدخول بصلاحية مدير (FR-A1)، حماية المسارات (NFR-SEC2) |
| **الوحدة 3** | وحدة الحجوزات والطلب (Booking & Ordering) | إدارة طلبات الحجز (FR-A2) |
| **الوحدة 5** | وحدة الإدارة والتحليل (Admin Management & Analytics) | **الوحدة الأساسية:** لوحة التحكم الشاملة، إدارة الخدمات (FR-A3)، المتجر (FR-A4)، المستخدمين (FR-A5)، التقارير (FR-A6)، الشكاوى (FR-A7)، المحتوى (FR-A9)، التصدير (FR-A10)، الصلاحيات (FR-A11) |
| **الوحدة 6** | وحدة الذكاء الاصطناعي والتفاعل اللحظي (AI & Realtime) | الجدولة الذكية (FR-A8)، الإشعارات اللحظية |
