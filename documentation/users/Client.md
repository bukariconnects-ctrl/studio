# العميل المسجل (Client)

---

## الوصف

هو المحرك المالي للنظام، يمتلك حساباً موثقاً وصلاحيات كاملة لإجراء الحجوزات وعمليات الشراء والتقييم. يمثل المستخدم الأساسي الذي يُدر الدخل للإستوديو من خلال حجز جلسات التصوير وشراء المعدات والإكسسوارات. يتمتع بتجربة مخصصة تشمل توصيات ذكية ومساعد AI لتنسيق المظهر.

---

## المهام التفصيلية

| رمز المتطلب | المهمة | الوصف التفصيلي |
| :--- | :--- | :--- |
| **FR-C1** | المصادقة وتسجيل الدخول | تسجيل الدخول باستخدام البريد الإلكتروني وكلمة المرور عبر Supabase Auth مع تخزين الجلسة في Cookies مشفرة ودعم Server-side Auth. |
| **FR-C2** | إدارة الملف الشخصي | تحديث البيانات الشخصية (الاسم، الهاتف، الصورة، العنوان) عبر Server Actions مع التحقق عبر Zod. |
| **FR-C3** | حجز المواعيد والجلسات | حجز جلسات التصوير واختيار المصور والخدمة/الباقة والوقت المناسب. يتم ربط الحجز بالمصور في جدول bookings مع حالة أولية "قيد الانتظار". |
| **FR-C4** | التحقق الآلي من الإتاحة | التحقق التلقائي من توفر المصور في التاريخ والوقت المطلوب عبر Supabase RPC (check_photographer_availability) لمنع تداخل المواعيد. |
| **FR-C5** | التسوق وإدارة السلة | إضافة المنتجات إلى سلة المشتريات وإدارتها (تعديل الكميات، الحذف) باستخدام Zustand مع حفظ الحالة في localStorage. |
| **FR-C6** | الدفع الإلكتروني وإصدار الفواتير | إتمام عمليات الدفع الآمن عبر بوابة Stripe واستلام الفواتير بصيغة PDF. يتم تحديث حالة الحجز/الطلب عبر Webhook. |
| **FR-C7** | التوصيات الذكية ومساعد المظهر | استلام توصيات مخصصة من محرك الذكاء الاصطناعي بناءً على السلوك الشرائي (pgvector)، واستخدام مساعد AI لتنسيق المظهر عبر Edge Functions. |
| **FR-C8** | إدارة الحجوزات السابقة والحالية | تتبع حالة الحجوزات (قيد الانتظار، مؤكد، مكتمل، ملغى) والطلبات السابقة مع تحديث لحظي عبر React Query و Polling. |
| **FR-C9** | التقييم والمراجعات | تقييم المصورين والخدمات بعد إتمام الجلسة (1-5 نجوم + تعليق). يتم التحقق عبر RLS أن الحجز مكتمل قبل السماح بالتقييم. |
| **FR-C10** | استرجاع كلمة المرور | استعادة كلمة المرور عبر رابط "إعادة تعيين" آمن يُرسل للبريد الإلكتروني باستخدام Supabase Auth Email Recovery. |
| **FR-C11** | سجل النشاطات الشخصي | استعراض مفصل للفواتير والحجوزات والطلبات السابقة كسجل موحد لنشاط العميل. |

## الوحدات البرمجية المرتبطة

| الوحدة | الاسم | نوع التفاعل |
| :--- | :--- | :--- |
| **الوحدة 1** | وحدة الأساس والهوية (Core Foundation & Identity) | تسجيل الدخول (FR-C1)، إدارة الملف الشخصي (FR-C2)، استرجاع كلمة المرور (FR-C10)، حماية المسارات (NFR-SEC2) |
| **الوحدة 2** | وحدة الكتالوج والعرض (Catalog & Display) | تصفح الخدمات والمنتجات، إدارة سلة المشتريات (FR-C5) |
| **الوحدة 3** | وحدة الحجوزات والطلب (Booking & Ordering) | حجز المواعيد (FR-C3)، التحقق من الإتاحة (FR-C4)، الدفع والفواتير (FR-C6)، إدارة الحجوزات (FR-C8)، سجل النشاطات (FR-C11) |
| **الوحدة 6** | وحدة الذكاء الاصطناعي والتفاعل اللحظي (AI & Realtime) | التوصيات الذكية (FR-C7)، التقييمات (FR-C9)، الإشعارات اللحظية |
