# المصور (Photographer)

---

## الوصف

هو المستخدم التقني المسؤول عن الجانب الإنتاجي في النظام. تتركز مهامه حول إدارة وقته وتنفيذ جلسات التصوير وتسليم المخرجات الرقمية (الصور). يمتلك لوحة تحكم مخصصة خفيفة تعرض جدول المهام المسندة إليه فقط، ويتلقى إشعارات لحظية عند إسناد مهام جديدة. يتم إنشاء حسابه من قبل المدير ولا يمتلك صلاحيات إدارية أو تجارية.

---

## المهام التفصيلية

| رمز المتطلب | المهمة | الوصف التفصيلي |
| :--- | :--- | :--- |
| **FR-P1** | تسجيل الدخول بصلاحية مصور | الدخول إلى النظام مع التحقق من دور "photographer" في Supabase Metadata. يتم توجيهه تلقائياً إلى لوحة تحكم المصور (`/photographer`). |
| **FR-P2** | استعراض جدول المهام المنظم | الوصول إلى جدول المهام الخاص به فقط (الجلسات المسندة إليه) عبر سياسات RLS التي تضمن خصوصية البيانات. يعرض الجلسات مرتبة حسب التاريخ والوقت. |
| **FR-P3** | عرض تفاصيل الجلسة للتحضير | الاطلاع على تفاصيل كل جلسة: بيانات العميل (الاسم، الهاتف)، نوع الباقة/الخدمة، الموقع، ملاحظات العميل الخاصة بالتحضير. يتم جلب البيانات عبر Server Components. |
| **FR-P4** | تحديث حالة الجلسة | الضغط على زر "إتمام الجلسة" لتحديث حالة الحجز إلى "تم التنفيذ" (completed) مع تسجيل طابع زمني لانتهاء المهمة عبر Server Action. |
| **FR-P5** | رفع مخرجات العمل (الصور) | رفع الصور النهائية إلى ألبومات خاصة بكل جلسة عبر Supabase Storage مع دعم Resumable Uploads لضمان عدم ضياع الرفع عند انقطاع الإنترنت. يتم تخزين روابط الصور في جدول `album_photos`. |
| **FR-P6** | تلقي الإشعارات الفورية | استلام إشعارات لحظية عند إسناد مهام جديدة أو تغيير حالة الحجوزات عبر Supabase Realtime (WebSocket). تظهر كـ Toast Notification دون الحاجة لتحديث الصفحة. |

## الوحدات البرمجية المرتبطة

| الوحدة | الاسم | نوع التفاعل |
| :--- | :--- | :--- |
| **الوحدة 1** | وحدة الأساس والهوية (Core Foundation & Identity) | تسجيل الدخول بصلاحية مصور (FR-P1)، حماية المسارات عبر Middleware (NFR-SEC2) |
| **الوحدة 4** | وحدة العمليات والتنفيذ (Operations & Fulfillment) | **الوحدة الأساسية:** جدول المهام (FR-P2)، تفاصيل الجلسات (FR-P3)، تحديث الحالة (FR-P4)، رفع الصور (FR-P5) |
| **الوحدة 6** | وحدة الذكاء الاصطناعي والتفاعل اللحظي (AI & Realtime) | استقبال الإشعارات اللحظية (FR-P6)، الجدولة الذكية |

## صلاحيات الوصول للبيانات (Tables)

| الجدول | قراءة | كتابة | ملاحظات |
| :--- | :---: | :---: | :--- |
| `profiles` | ✅ (عام) | ✅ (ملفه فقط) | بياناته الشخصية |
| `photographers` | ✅ (عام) | ✅ (بياناته فقط) | بيانات مهنية (التخصص، التوفر) |
| `bookings` | ✅ (حجوزاته فقط) | ✅ (تحديث الحالة فقط) | جدول المهام (FR-P2) وتحديث الحالة (FR-P4). **RLS:** `photographer_id = auth.uid()` |
| `albums` | ✅ (ألبوماته فقط) | ✅ (إنشاء/تعديل ألبوماته) | إدارة ألبومات الصور (FR-P5) |
| `album_photos` | ✅ (صور ألبوماته) | ✅ (رفع صور لألبوماته) | رفع مخرجات العمل (FR-P5) |
| `photographer_unavailability` | ✅ (فتراته فقط) | ✅ (فتراته فقط) | إدارة فترات عدم التوفر |
| `notifications` | ✅ (إشعاراته فقط) | ✅ (تحديد كمقروء) | الإشعارات اللحظية (FR-P6) |
| `services` | ✅ | ❌ | قراءة تفاصيل الخدمات للتحضير |
| `packages` | ✅ | ❌ | قراءة تفاصيل الباقات للتحضير |
| `reviews` | ✅ (العامة) | ❌ | الاطلاع على تقييماته |
| `user_roles` | ✅ (أدواره فقط) | ❌ | التحقق من الصلاحيات |
| `roles` | ✅ | ❌ | قراءة الأدوار |

> **ملاحظة:** سياسات RLS تضمن أن المصور يرى **فقط** الجلسات المسندة إليه. لا يمكنه الوصول إلى جداول المصورين الآخرين أو بيانات العملاء غير المرتبطة بجلساته. كل عمليات رفع الصور تتم عبر Supabase Storage مع سياسات أمان تتحقق من أن المصور هو المسند إليه الحجز (NFR-SEC2).
