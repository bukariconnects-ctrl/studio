# الزائر (Visitor)

---

## الوصف

هو المستخدم العام الذي لم يقم بتسجيل الدخول بعد. يمثل الواجهة التسويقية للإستوديو، وهدفه استكشاف الخدمات وبناء الثقة قبل التحول إلى عميل مسجل. لا يمتلك حساباً في النظام ولا يمكنه إجراء أي عمليات شراء أو حجز.

---

## المهام التفصيلية

| رمز المتطلب | المهمة | الوصف التفصيلي |
| :--- | :--- | :--- |
| **FR-V1** | تصفح الخدمات والباقات | استعراض كتالوج خدمات التصوير (زفاف، بورتريه، منتجات...) والباقات المتاحة مع أسعارها وتفاصيلها، عبر Server Components لضمان سرعة التحميل وتوافق SEO. |
| **FR-V2** | تصفح المتجر والمعدات | استعراض منتجات المتجر (كاميرات، عدسات، إكسسوارات) مع حالة المخزون اللحظية والأسعار والصور المحسّنة عبر Next.js Image Optimization. |
| **FR-V3** | البحث المتقدم | استخدام محرك بحث متقدم (Supabase Postgres Search) للوصول السريع إلى الخدمات والمنتجات والباقات عبر الأسماء والأوصاف والتصنيفات. |
| **FR-V4** | استعراض فريق المصورين | الاطلاع على ملفات المصورين الشخصية ونماذج أعمالهم (Portfolio) وتقييماتهم وتخصصاتهم. |
| **FR-V5** | إنشاء حساب جديد | التسجيل في المنصة عبر Supabase Auth مع التحقق من صحة البيانات لحظياً باستخدام React Hook Form و Zod. |
| **FR-V6** | عرض السياسات والشروط | قراءة صفحات سياسة الخصوصية وشروط الخدمة والأسئلة الشائعة (صفحات ثابتة Static Pages). |

---

## الوحدات البرمجية المرتبطة

| الوحدة | الاسم | نوع التفاعل |
| :--- | :--- | :--- |
| **الوحدة 1** | وحدة الأساس والهوية (Core Foundation & Identity) | إنشاء حساب جديد (FR-V5)، عرض السياسات (FR-V6) |
| **الوحدة 2** | وحدة الكتالوج والعرض (Catalog & Display) | تصفح الخدمات والباقات (FR-V1)، تصفح المتجر (FR-V2)، البحث المتقدم (FR-V3)، استعراض المصورين (FR-V4) |

---

## صلاحيات الوصول للبيانات (Tables)

| الجدول | قراءة | كتابة | ملاحظات |
| :--- | :---: | :---: | :--- |
| `services` | ✅ | ❌ | تصفح الخدمات (FR-V1) |
| `service_categories` | ✅ | ❌ | تصنيفات الخدمات |
| `packages` | ✅ | ❌ | تصفح الباقات (FR-V1) |
| `package_services` | ✅ | ❌ | تفاصيل محتوى الباقات |
| `products` | ✅ | ❌ | تصفح المنتجات (FR-V2) |
| `product_categories` | ✅ | ❌ | تصنيفات المنتجات |
| `product_images` | ✅ | ❌ | صور المنتجات |
| `photographers` | ✅ | ❌ | بيانات المصورين (FR-V4) |
| `profiles` | ✅ | ❌ | بيانات المصورين العامة |
| `reviews` | ✅ | ❌ | تقييمات المصورين المرئية فقط |
| `system_settings` | ✅ | ❌ | محتوى الصفحات الثابتة (FR-V6) |
| `auth.users` | ❌ | ✅ | إنشاء حساب جديد فقط (FR-V5) عبر Supabase Auth |

> **ملاحظة:** جميع صلاحيات القراءة للزائر تتم عبر سياسات RLS العامة (Public SELECT). لا يمتلك الزائر أي صلاحيات كتابة على جداول البيانات باستثناء إنشاء حساب عبر Supabase Auth.
